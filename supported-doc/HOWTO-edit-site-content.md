# How to edit site content

*For content writers, admins and super-admins.*

The storefront's designed sections (hero, mission band, call-to-action) show **text and images that
you can edit** — the layout and design stay fixed.

## Steps

1. Sign in to the admin console and open **Content management → Site Content**.
2. Choose the **page** (Home) at the top. Its sections appear as cards.
3. Use the **Arabic / English** toggle to choose which language you are editing. Arabic is the
   default; English is an overlay shown to English visitors.
4. Edit each field:
   - **Text** fields — type the new wording.
   - **Image** fields (e.g. the hero image) — click the file picker and choose a new image; a preview
     appears.
   - **Link** fields — enter the target (e.g. `/shop` or a full URL).
   - Toggle **Active** off to hide a block (the storefront falls back to its built-in copy).
5. Press **Save section**. The change appears on the storefront after a refresh, in the language you
   edited.
6. Use **Preview storefront** to open the live page in a new tab.

> **What you cannot break:** you can only change words, images, links and the active flag. Section
> layout, design and the block identifiers are fixed in code, so editing content can never change the
> design. Rich-text fields keep only basic formatting (bold, italic, line breaks); anything else is
> removed automatically.

Every edit is recorded in **System → Audit Log** (visible to admins).

# كيفية تعديل محتوى الموقع

*لكتّاب المحتوى والمدراء والمدراء العامّين.*

تعرض أقسام المتجر المصمّمة (الواجهة، شريط الرسالة، الدعوة للإجراء) **نصوصًا وصورًا يمكنك تعديلها** —
بينما يبقى التخطيط والتصميم ثابتَين.

## الخطوات

1. سجّل الدخول إلى لوحة الإدارة وافتح **إدارة المحتوى ← محتوى الموقع**.
2. اختر **الصفحة** (الرئيسية) في الأعلى، فتظهر أقسامها كبطاقات.
3. استخدم مفتاح **العربية / الإنجليزية** لاختيار لغة التحرير. العربية هي الأساس، والإنجليزية طبقة
   تظهر للزوار الناطقين بالإنجليزية.
4. عدّل كل حقل:
   - حقول **النص** — اكتب الصياغة الجديدة.
   - حقول **الصورة** (مثل صورة الواجهة) — انقر أداة اختيار الملف واختر صورة جديدة، فتظهر معاينة.
   - حقول **الرابط** — أدخل الوجهة (مثل `/shop` أو رابطًا كاملًا).
   - أطفئ **مُفعّل** لإخفاء كتلة (يعود المتجر عندئذٍ إلى نصّه المدمج).
5. اضغط **حفظ القسم**. يظهر التغيير على المتجر بعد التحديث، وباللغة التي حرّرتها.
6. استخدم **معاينة المتجر** لفتح الصفحة الحيّة في تبويب جديد.

> **ما لا يمكنك كسره:** يمكنك تغيير النصوص والصور والروابط وحالة التفعيل فقط. أما تخطيط الأقسام
> والتصميم ومعرّفات الكتل فثابتة في الكود، لذا لا يمكن لتعديل المحتوى أن يغيّر التصميم. تحتفظ حقول
> النص المنسّق بتنسيق أساسي فقط (غامق، مائل، أسطر جديدة)، ويُزال ما عداه تلقائيًا.

يُسجَّل كل تعديل في **النظام ← سجل التدقيق** (المتاح للمدراء).
